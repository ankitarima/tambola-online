# 🪔 Diwali Tambola Dhamaka - Live Indian Number Anchor

A modern, high-energy **Tambola (Housie) Random Number Generator & Indian Voice Anchor** crafted specifically for office parties, projector setups, and festive Diwali celebrations.

---

## 🌟 Highlights & Features

- **Colossal Center Display**: Displays the drawn number in huge font (`14rem`), legible from across the entire office hall or on a conference projector/TV.
- **Indian Voice Anchor & Classic Nicknames**:
  - Web Speech API speech synthesis tuned for Indian accents (`en-IN` & `hi-IN`).
  - Traditional Indian Tambola rhymes and calls (e.g., *"Number 7! Satte pe Satta! Lucky Seven!"*, *"Number 22! Two Little Ducks, Baais!"*, *"Number 88! Two Fat Ladies!"*, *"Number 90! Top of the House, Baras Gaya Badal!"*).
  - 4 Calling Styles: **Desi Hinglish**, **Indian English**, **Pure Hindi**, and **Quick Numbers**.
- **No Repeat Guarantee**: Mathematical uncalled pool prevents repeated numbers; automatically handles all 90 numbers.
- **One-Click & Keyboard Controls**:
  - `SPACE` or `ENTER`: Draw next number
  - `R`: Repeat audio announcement
  - `A`: Toggle Auto-Play mode
  - `M`: Mute / Unmute
  - `F`: Fullscreen mode (ideal for TV/projector)
- **Auto-Play Mode**: Adjustable countdown interval (5s, 7s, 10s, 12s, 15s) with a visual timer.
- **Master 1-90 Interactive Board**:
  - 10x9 grid tracking all called numbers with golden glow and call sequence orders.
  - Hover or click any number to hear its announcement.
- **Recent Numbers Carousel**: Instant glance at the last 7 called numbers.
- **Office Claim Verifier**: Built-in prize verification tool for *Early 5*, *Lines*, *Four Corners*, *Full House* to avoid any office arguments!
- **Zero Loss / Auto-Save**: Auto-persists the board state in `localStorage` so an accidental tab close or page refresh never loses the party's game.
- **Diwali Festive Aesthetics**: Floating Diyas, ambient golden sparkles, hanging Kandil lanterns, Toran garland, and celebratory confetti/cracker sound effects using Web Audio API (100% offline, zero missing asset errors).

## 🚀 How to Run

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Start development server
npm run dev

# Or build & preview
npm run build
npm run preview
```

Open `http://localhost:5173` or `http://localhost:4173` in your browser.
Press `F` to enter Fullscreen mode on your office projector or TV!
